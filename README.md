# Simulatore Predittivo Pro
Dixon-Coles + Elo dinamico. Dati automatici da Football-Data.org e The Odds API.

## Setup
1. Aggiungi secrets `FDKEY` e `ODDSKEY` in Settings > Secrets
2. Vai su Actions > Update Football Data > Run workflow
3. Apri https://migueltequila.github.io/simulatore-calcio-pro/
